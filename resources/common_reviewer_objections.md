# 常见审稿风险清单

- 研究问题风险：现实背景很强，但没有形成管理学解释问题。
  来源主题类别：公共政策与政府治理；数字经济与数据治理；来源方法类别：跨方法；来源文章类型：跨类型；证据等级：中；是否可用于用户论文判断：谨慎。

- 方法性风险：识别策略不足却使用强因果语言。
  来源主题类别：跨主题；来源方法类别：大样本实证；来源文章类型：机制检验型实证论文；证据等级：高；是否可用于用户论文判断：是。

- 机制风险：机制检验存在，但未对应理论机制路径。
  来源主题类别：跨主题；来源方法类别：大样本实证；来源文章类型：机制检验型实证论文；证据等级：高；是否可用于用户论文判断：是。

- 稳健性风险：稳健性检验存在但未回应核心威胁。
  来源主题类别：跨主题；来源方法类别：双重差分；大样本实证；来源文章类型：政策冲击评估型；证据等级：高；是否可用于用户论文判断：是。

- 文字风险：政策口号、AI 化表达、空泛贡献和过度因果化会降低审稿可信度。
  来源主题类别：跨主题；来源方法类别：跨方法；来源文章类型：跨类型；证据等级：高；是否可用于用户论文判断：是。

- 低置信度提示，不宜作为强判断依据：投稿层级判断只能作为粗略风险提示，不能等同录用概率。
  来源主题类别：跨主题；来源方法类别：跨方法；来源文章类型：跨类型；证据等级：低；是否可用于用户论文判断：谨慎。
