# 《管理世界》风格 CSSCI 管理学论文审稿与重构 Skill

本仓库提供一个面向 Codex 的论文审稿与重构 Skill，用于辅助评估中文 CSSCI 管理学论文在问题意识、文献定位、理论机制、实证逻辑、证据边界、贡献表达和文字风格上的结构性质量。

该 Skill 的目标不是模仿或复刻《管理世界》文章，而是把近年管理学论文中较稳定的写作结构、审稿关注点和证据约束转化为一套可复用的诊断框架，帮助作者识别稿件中的关键短板，并形成可执行的修改路径。

## 适用场景

本 Skill 适合用于以下任务：

- 对 CSSCI 管理学论文进行审稿式诊断；
- 判断论文是否形成清晰的“问题-理论-方法/论证-证据-贡献”闭环；
- 检查研究问题、文献缺口、理论机制和贡献表达是否匹配；
- 审查实证论文的数据、变量、模型、识别、稳健性、机制检验和异质性分析；
- 审查非实证论文的理论推理、案例证据链和论证结构；
- 将政策口号化、AI 化、空泛化和过度因果化表达降调为更克制的学术表达；
- 给出分优先级的重构建议和下一步修改清单。

## 方法来源与边界

本 Skill 基于本地 2024-2026 年《管理世界》PDF 语料的自动抽取、自动分类、自动补全和置信度分层结果形成。仓库只保留经过归纳后的审稿规则、结构模式和风险提示，不包含 PDF 原文、全文摘录、原始语料、用户论文或私人分析输出。

需要特别注意：

- 本 Skill 不代表《管理世界》编辑部、匿名审稿人或任何官方录用标准；
- 自动归纳结果只可作为审稿辅助，不可替代人工阅读全文后的学术判断；
- 官方栏目自动识别结果不稳定，因此不作为判断依据；
- 高置信度规则可用于结构化初审，中置信度规则用于提出修改建议，低置信度内容只能作为风险提示；
- 投搞潜力或投搞风险判断只能作为粗略参考，不能等同于录用概率。

## 核心诊断维度

Skill 在使用时通常围绕七个维度展开：

1. 问题意识：现实背景是否被转化为可解释的管理学问题；
2. 文献定位：文献缺口是否说明既有解释为何不足，而不是仅强调研究较少；
3. 理论机制：核心概念、作用路径、边界条件和可观察证据是否连贯；
4. 实证逻辑或论证逻辑：数据、变量、模型、识别策略或案例证据链是否支持结论；
5. 证据强度：结论和政策建议是否超出证据边界；
6. 贡献表达：理论贡献、经验贡献和政策启示是否各有依据；
7. 文字风格：是否存在口号化、空泛化、AI 化、过度因果化或段落任务不清的问题。

## 工作流程

典型使用流程如下：

1. 先判断用户论文最接近的文章类型，例如理论机制建构型、机制检验型实证论文、政策冲击评估型、制度情境解释型、文本分析与政策评价型、案例机制提炼型或方法组合型。
2. 再依据资源文件中的文章范式、实证逻辑、理论机制、引言结构、贡献表达和文字风格规则，选择最相关的对标框架。
3. 区分结构性致命问题、方法性问题、证据边界问题和文字表达问题。
4. 给出总体判断、匹配度评估、最严重问题、逻辑审查、机制审查、表达优化建议和下一步操作清单。
5. 对每一类判断标注置信度，避免把自动推断写成确定性结论。

## 输入建议

为了获得较完整的诊断结果，建议至少提供以下内容：

- 摘要；
- 引言；
- 文献综述；
- 理论机制或研究假设；
- 研究设计；
- 数据来源与样本说明；
- 变量说明；
- 模型设定；
- 实证结果或案例材料；
- 稳健性检验；
- 机制检验；
- 异质性分析；
- 结论与政策建议。

若稿件不是实证论文，可以提供理论推理、案例材料、访谈材料、政策文本、分析框架和论证结构，由 Skill 转为相应的论证逻辑或证据链审查。

## 版权与学术诚信

本仓库不包含、也不应加入任何论文原文、PDF、CAJ、用户稿件、全文摘录或可识别个人信息。使用本 Skill 时应遵守以下原则：

- 不逐字仿写任何论文；
- 不拼接、复刻或改写原文段落；
- 不把机器推断写成官方标准；
- 不承诺录用结果；
- 不用政策重要性替代理论贡献；
- 不用复杂方法掩盖研究问题不足；
- 不把弱证据写成强因果结论。
